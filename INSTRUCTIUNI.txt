KEYSTOCKS PWA — PACHET PENTRU INSTALARE PE IPHONE

Acest pachet trebuie publicat pe HTTPS (de exemplu GitHub Pages), apoi deschis în Safari.
Nu deschide index.html direct din Fișiere; acel mod afișează doar previzualizarea fișierului.

PAȘI SIMPLI CU GITHUB PAGES
1. Pe laptop, intră pe https://github.com și creează un cont sau autentifică-te.
2. Creează un repository nou numit keystocks-app și selectează Public.
3. În repository apasă Add file -> Upload files.
4. Încarcă TOATE fișierele din acest folder: index.html, manifest.webmanifest, service-worker.js, icon-180.png, icon-192.png, icon-512.png.
5. Apasă Commit changes.
6. Intră în Settings -> Pages.
7. La Build and deployment, alege Deploy from a branch; Branch: main; Folder: /(root); apasă Save.
8. Așteaptă publicarea și copiază adresa afișată, de forma https://NUME.github.io/keystocks-app/
9. Deschide acea adresă în Safari pe iPhone.
10. Apasă Share (pătratul cu săgeată în sus) -> Add to Home Screen -> Add.
11. Deschide KEYSTOCKS de pe ecranul principal și lasă pagina să se încarce o dată cu internet. Apoi poate fi folosită offline.

IMPORTANT DESPRE DATE
- Produsele și mișcările se salvează local pe iPhone, în browserul aplicației.
- Nu există sincronizare automată între dispozitive.
- Fă periodic Backup din aplicație și păstrează fișierul JSON într-un loc sigur.
- Dacă publici codul pe GitHub, codul aplicației este public; datele tale de stoc NU sunt încărcate pe GitHub.
